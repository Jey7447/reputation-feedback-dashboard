# n8n Workflows

This folder contains the three automation workflow exports used by the project.

- feedback-intelligence/feedback-intelligence.json — feedback analysis and routing
- feedback-request-orchestrator/feedback-request-orchestrator.json — feedback request delivery
- approved-response-delivery/approved-response-delivery.json — approved response delivery

The public copies have credential IDs and the n8n instance ID removed. No API keys or passwords were included.
